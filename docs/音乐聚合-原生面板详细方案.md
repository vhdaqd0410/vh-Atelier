## 一、为什么做原生面板

现在面板是 iframe 嵌 lxserver 的 Web 播放器。它**功能完整、随 lxserver 升级自动更新**，但有三件事做不到：

| 做不到的事 | 影响 |
|---|---|
| 与插件的**音乐库**打通 | 下载的歌要手动去音乐库找 |
| **插入 PR 时间轴 / 拖进 PR** | 得先下载到本地再手动导入 |
| 视觉风格统一 | 播放器的配色/排版与插件不一致 |
| 深色模式跟随 | 跨源 iframe 写不了对方 localStorage |

原生面板解决这四件事。**iframe 保留**（当"完整播放器"用），原生面板作为"干活用的快捷入口"。

## 二、接口清单（复用 lxserver REST API，不改它）

| 功能 | 接口 | 参数 |
|---|---|---|
| **多平台搜索** | `GET /api/music/search` | `source`(wy/tx/kw/kg/mg) + `name` + `type=song` + `limit` + `page` |
| **取播放直链** | `POST /api/music/url` | body `{songInfo: {…}, quality: '320k'}` |
| **歌词** | `GET /api/music/lyric` | `source` + `songmid` |
| **热搜词** | `GET /api/music/hotSearch` | `source` |
| **榜单** | `GET /api/music/leaderboard/boards` | `source` |
| **下载** | `POST /api/music/download` | `{url, filename…}`（需先取直链） |

**搜索返回的字段**（实测）：
```json
{ "singer": "周杰伦、温岚", "name": "屋顶", "albumName": "…", "source": "wy",
  "interval": "05:19", "songmid": 5257138, "img": "http://…jpg",
  "types": [{"type":"128k","size":"4.87 MB"}, {"type":"320k","size":"12.17 MB"}] }
```

## 三、UI 布局方案

### 整体结构（三步式，与语音克隆/扒歌面板一致）

```
┌─ 音乐聚合 ─────────────────────────────────────────────────┐
│ ● 已就绪 · 本地服务   [来源: 本地▾]  [↻] [◐] [↗]            │  ← 状态条
├────────────────────────────────────────────────────────────┤
│ 🔍 [搜索歌曲 / 歌手…            ]  [搜索]   [榜单▾]        │  ← 搜索区
│ 平台： (●)网易云 (○)QQ (○)酷我 (○)酷狗 (○)咪咕 (○)全部    │
├────────────────────────────────────────────────────────────┤
│ 结果 20 条                                                        │
│ ┌──────────────────────────────────────────────────────────┐│
│ │♪ 屋顶            周杰伦、温岚    05:19  网易云            ││  ← 结果行
│ │                                      [试听][下载][→PR] ││
│ ├──────────────────────────────────────────────────────────┤│
│ │♪ 晴天            周杰伦          04:29  网易云            ││
│ │                                      [试听][下载][→PR] ││
│ └──────────────────────────────────────────────────────────┘│
├────────────────────────────────────────────────────────────┤
│ 试听条（点▶后展开，与人声分离同款）                            │
│ ▶ ━━━━━━━━●──────────── 1:23 / 4:29    🔊  ———●———  1.0x    │  ← 波形播放器
└────────────────────────────────────────────────────────────┘
```

### 关键交互

**① 结果行**（复用现成的 `.sep-res-item` 样式，与人声分离一致）

| 元素 | 交互 |
|---|---|
| `▶` | 在行内展开波形试听（wavesurfer，走直链） |
| `试听` | 同上（大一点的入口） |
| `下载` | 取直链 → 存到音乐库目录 → 完成提示 |
| `→PR` | 下载到本地后，插入时间轴（复用 `vcInsertPayload`） |
| 整行拖拽 | CEP DnD 直接拖进 PR（需先下载到本地） |

**② 平台筛选**：单选 chip，切换后重新搜索该平台。选"全部"则并发搜 5 个平台，结果按平台分组或混合去重。

**③ 榜单**：下拉选平台 + 榜单类型（热歌/新歌），结果同样进列表。

**④ 试听播放器**：复用扒歌面板的波形播放器（`wavesurfer` + Blob 加载），**不新写**。

## 四、分阶段实施（建议不要一次做完）

### 阶段 1：搜索 + 试听（约 1.5 天）

- 搜索框 + 平台切换 + 结果列表
- 点行展开波形试听
- **验证点**：直链时效性（取到的 URL 能用多久）

**这一阶段做完就能替代 iframe 的主要用途。**

### 阶段 2：下载 + 导入音乐库（约 0.5 天）

- 下载按钮 → 存到音乐库目录（复用 `/song/download` 的落盘逻辑，或调 lxserver 的 download）
- 完成后音乐库面板自动可见（复用现成的目录刷新）

### 阶段 3：插入时间线 + 拖拽（约 0.5 天）

- `→PR` 按钮 → 复用 `vcInsertPayload` / `vcInsertToTimelineStr`
- 整行拖拽 → CEP DnD 协议
- **注意**：拖拽要求文件已在本地，需先下载（可做成"拖时自动下载"）

### 阶段 4（可选）：歌单 / 歌词 / 收藏

如果前三个阶段用着顺手再考虑。

## 五、风险与对策

| 风险 | 说明 | 对策 |
|---|---|---|
| **直链时效** | 平台直链是临时的，可能几分钟后失效 | 播放/下载前**实时取**，不缓存 URL；失败自动重取一次 |
| **版权/合规** | 与 lxserver 同源风险 | 已在 lxserver 侧说明；插件只做客户端 |
| **接口变动** | lxserver 升级可能改接口字段 | 断言锁住字段名；接口失败时降级提示，不静默 |
| **音源不可用** | 用户配的源失效 | 明确提示"该平台无可播源"，引导去源管理 |

## 六、和 iframe 的关系

**两者并存，不互斥**：

| 场景 | 用哪个 |
|---|---|
| 想听歌、逛歌单、看歌词 | **iframe**（完整播放器） |
| 想搜首歌下载进音乐库 | **原生区** |
| 想搜段音乐插进时间线 | **原生区** |
| 深色模式 | **iframe**（播放器内自己设一次） |

**放置方式**（两种选一）：

- **方案 X**：同一个面板，上半 iframe 下半原生（切换标签页）
- **方案 Y**：加个开关「简洁模式 / 完整播放器」，一键切换

我倾向 **方案 Y** —— 交互更清晰，不用在同一个面板里挤两块内容。
