▸ 🔧 PR 版本转换 未选择文件
高版本 PR 做的样式/工程，低版本打开会报「保存于更新版本」。 选文件 → 选目标版本 → 转换。高版本一定能开低版本，默认转 PR 2021 即可。
▸ 🔤 缺失字体修复 检测中…
PR 2021 及更早版本不支持可变字体。Windows 自带的 Bahnschrift 是可变字体， 高版本样式里存的 Bahnschrift-Bold 会被低版本判为「字体不可用」。 这里装一个从该字体固化出来的静态 Bold（字重与原设计一致）。 字体随插件附带，免管理员、可随时卸载；装完重启 PR 生效。
